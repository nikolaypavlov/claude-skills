# Українські правила: адаптований STE + ДСТУ 3966:2009

Правила для переписування українського технічного тексту. Основа - механічні
правила ASD-STE100, доповнені специфікою української мови та стильовими
настановами ДСТУ 3966:2009.

## СЛОВА

- Одна назва - одне поняття. Не називайте ту саму річ двома різними словами.
- Вживайте усталені українські терміни. Запозичуйте лише тоді, коли українського
  відповідника немає.
- Без кальок і росіянізмів:
  - "приймати участь" -> "брати участь"
  - "у якості" -> "як"
  - "являється" -> "є"
  - "даний" -> "цей"
  - "існуючий" -> "наявний", "чинний"
  - "у відповідності до" -> "відповідно до"
  - "вірний" (у значенні правильний) -> "правильний"
- Без порожніх фраз ШІ-стилю: "варто зазначити", "слід відмітити", "в даному
  випадку", "давайте розглянемо", "не можна не".
- Без маркетингових прикметників: потужний, безшовний, революційний, передовий,
  неперевершений.

## ДІЄСЛОВА

- Активний стан. "Парсер читає файл", а не "файл читається парсером".
- Без пасиву на -ся, коли виконавець відомий.
- Для результату вживайте безособові форми на -но/-то: "зміни внесено", "файл
  збережено".
- Без активних дієприкметників на -учий/-ючий: "працюючий" -> "який працює".
- Дієслово замість ланцюжка з віддієслівним іменником (ДСТУ 3966): "виконати
  аналіз" -> "проаналізувати", "здійснити перевірку" -> "перевірити".
- Розрізняйте дію, подію і наслідок там, де це змінює зміст: "розробляння"
  (процес), "розроблення" (завершена дія), "розробка" (результат). Застосовуйте
  практично, без педантизму.

## РЕЧЕННЯ

- Одна інструкція - одне речення. Максимум 20 слів (інструкція), 25 (опис).
- Природний порядок слів: підмет, присудок, додаток. Тримайте дієслово близько
  до підмета.

## ПУНКТУАЦІЯ

- Без крапки з комою. Напишіть два речення.

## СТРУКТУРА

- Один абзац - одна тема, не більше шести речень.
- Кроки оформлюйте нумерованим списком: одна дія на пункт, наказовий спосіб.
- Умову ставте перед командою. "Якщо файл існує, видаліть його."

Пишіть лише запитаний текст. Без вступу, без підсумку, без завершальних фраз.

## Режими

- **strict** - процедури, runbooks, тексти безпеки, повідомлення про помилки:
  застосовуйте всі правила та обидва ліміти довжини.
- **STE-flavored** - загальна проза (README, описи PR, документація):
  дотримуйтеся дисципліни речень, абзаців, активного стану і чистоти від кальок.
  Словник ширший, щоб текст звучав природно.

## Самоперевірка (українська)

Виконайте перед поверненням тексту:

1. Речення понад 20 слів? Розділіть.
2. Крапка з комою? Замініть крапкою.
3. Пасив із відомим виконавцем? Зробіть активним. Результат передайте формою на
   -но/-то.
4. Віддієслівний іменник замість дієслова ("виконати аналіз")? Замініть
   дієсловом.
5. Дієприкметник на -учий/-ючий? Замініть на "який ..." або на прикметник.
6. Калька чи росіянізм ("даний", "існуючий", "у якості")? Замініть українським
   відповідником.
7. Та сама річ названа двома словами? Виберіть одну назву.
8. Порожня фраза ("варто зазначити")? Видаліть її.
