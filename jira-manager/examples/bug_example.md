# Bug Ticket Example

## Summary
Login page - Users cannot log in with valid credentials

## Description

h3. Bug Description

Users are unable to log in to the application even when providing valid credentials. The login button remains inactive after entering username and password.

h3. Steps to Reproduce

# Navigate to the login page (https://app.example.com/login)
# Enter valid username: test@example.com
# Enter valid password
# Click "Log In" button
# Observe the error

h3. Expected Behavior

User should be successfully authenticated and redirected to the dashboard page.

h3. Actual Behavior

The login button shows a loading spinner for 2 seconds, then displays error message: "Authentication failed. Please try again."

h3. Environment

* *Browser/Device*: Chrome 118.0.5993.117, macOS 14.1
* *User Role*: Standard User
* *Date/Time*: 2024-11-12 14:30 UTC
* *Network*: Corporate VPN

h3. Screenshots/Logs

Console error:
{code}
POST https://api.example.com/auth/login 401 (Unauthorized)
Response: {"error": "invalid_credentials", "message": "Token validation failed"}
{code}

h3. Severity

*Critical* - Blocks all user access to the application

h3. Suggested Fix

The issue appears to be in the token validation logic. The authentication service may not be properly validating the session tokens generated by the login endpoint.

Check file: `src/services/auth.service.ts:45` - token validation method
