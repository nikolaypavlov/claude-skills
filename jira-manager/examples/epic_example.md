# Epic Ticket Example

## Summary
ICP Builder - Ideal Customer Profile Creation

## Description

h3. Epic Goal

Create a comprehensive Ideal Customer Profile (ICP) builder that guides users through a step-by-step process to define their target customer using AI-powered suggestions and templates.

h3. Business Value

* *Revenue Growth*: Enables users to identify and target high-value customer segments more effectively, increasing conversion rates by estimated 25%
* *User Engagement*: Provides interactive, guided experience that reduces time-to-value for new users from 2 weeks to 2 days
* *Competitive Differentiation*: First-to-market with AI-assisted ICP building in our category
* *Customer Retention*: Users who complete ICP builder show 40% higher retention rates based on pilot data

h3. Scope

h4. Phase 1: Core Questionnaire (Weeks 1-2)
* Step-by-step questionnaire interface with progress tracking
* Industry and company size selection
* Pain points and goals identification
* Budget and decision-making process questions
* Summary page with ICP preview

h4. Phase 2: AI Enhancements (Weeks 3-4)
* AI-powered suggestions for pain points based on industry
* Competitor analysis integration
* Automatic ICP scoring and quality metrics
* Similar ICP recommendations from database

h4. Phase 3: Export and Integration (Week 5)
* Export ICP as PDF, Word, or Markdown
* Save multiple ICPs per project
* Integration with CRM systems (Salesforce, HubSpot)
* ICP templates library (10+ pre-built templates)

h4. Phase 4: Collaboration (Week 6)
* Share ICP with team members
* Commenting and feedback system
* Version history and change tracking
* Team approval workflow

h3. Success Criteria

* *Adoption*: 60% of active users create at least one ICP within first month
* *Completion Rate*: 80% of users who start the questionnaire complete it
* *Time to Complete*: Average completion time under 15 minutes
* *Quality Score*: 90% of generated ICPs receive "Good" or "Excellent" quality rating
* *Export Usage*: 40% of completed ICPs are exported or integrated
* *NPS Impact*: +10 point increase in NPS among users who use ICP Builder

h3. Dependencies

* *Technical*:
  - AI/ML service integration (OpenAI API or internal model)
  - Database schema updates for ICP storage
  - PDF generation service
* *Team*:
  - Design team for UX/UI (estimated 40 hours)
  - Product team for template content creation (estimated 20 hours)
  - Marketing team for user education materials
* *External*:
  - CRM API access and documentation (Salesforce, HubSpot)
  - Legal review of data storage and AI usage policies
